# Operations runbook

Published reports, evidence, revisions and retractions are retained indefinitely by default. No cleanup routine deletes research. Operational rate buckets can be purged after 48 hours; completed job and run logs after a documented 90-day operational retention, subject to audit needs. Tokens referenced by report audit records stay as revoked metadata. Twelve Data stores only the latest validated quote snapshot per asset identity in a server-only cache; it retains no tick history. Clear that cache and disable display when trial permissions end.

| Symptom                        | Check and recovery                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Submission fails               | Read the stable HTTP error and Grok run history. 401: expired/revoked credential; 403: scope/desk/type; 422: schema/reference; 409: recover original payload or retrieve current revision head. Never regenerate content under a committed submission ID. Retry 429/temporary 5xx with Retry-After/backoff using unchanged bytes.                        |
| Receipt pending                | A receipt means committed storage. Inspect `private.processing_jobs` administratively. Confirm Cron/worker runs. No frontend client can change job state.                                                                                                                                                                                                |
| Job retries exhausted          | `attempts >= 10` stops automatic processing. Investigate the failed report and migration/function versions. Errors are sanitized as `derivation_failed`. Fix the cause; then reset attempts/available_at under an administrator session and process a bounded batch. Existing user controls survive replay. Do not delete the report to clear the queue. |
| Owner cannot load              | Check Auth session, public signup settings, owner UUID, table grants and RLS. A second account seeing no data is expected. Never authorize through user metadata. On sign-out private query state clears.                                                                                                                                                |
| Late or failed desk            | Receipt timestamps and supported `desk_runs` are authoritative. Schedule preferences alone do not mean researching/running. Inspect actual Grok run/approval/network/usage status. Chief of Staff publishes a brief with absent/stale coverage instead of inventing research.                                                                            |
| Realtime disconnect            | Foreground reconnect/poll checks canonical research storage. Feed shows New updates; users refresh explicitly. Query state deduplicates IDs and pagination uses receipt/ID ordering. Realtime is not a replay archive.                                                                                                                                   |
| Wrong instrument/missing quote | Keep the research-only asset visible; review its exact canonical identity and candidate provider alias, venue/expiry/currency and entitlement. Missing prices do not block qualifying suggestions. Never fill a gap with a neighboring contract.                                                                                                         |
| Stale/closed prices            | Check provider cadence, delay, quote time and market session. Closed differs from stale. With no provider, unavailable is expected; no alert claims quote-triggered detection.                                                                                                                                                                           |
| Credential leaked              | Revoke its row, rotate the secret on the Grok computer, retain stable bot ID, verify revoked token fails and retries deduplicate across rotation. Never log or paste tokens into prompts/source control.                                                                                                                                                 |
| Source invalid/retracted       | Append `report_events(kind='retraction', reason=...)` under the owning report/owner via a trusted operator; publish a desk revision for corrected research. Do not mutate old publication/evidence.                                                                                                                                                      |
| External alert absent          | External delivery is disabled. Only the in-app inbox is implemented. Do not claim email/push success from a storage receipt.                                                                                                                                                                                                                             |
| Restore needed                 | Restore to an isolated destination first, audit owner access, report counts and revisions, credentials and jobs, then perform a controlled cutover to the chosen production host. Prevent restored routines from submitting to production during the exercise.                                                                                           |

Safe job inspection (administrator only): select report ID, attempts, available time, completion and sanitized error. Do not dump credential tables or secret environments into logs. Future external-channel implementations need their own durable idempotent delivery records; research retries never imply permission to send messages.

Schedule behavior: store and install the user-selected IANA timezone explicitly; named-zone local morning/evening times follow DST, UTC offsets change. Confirm how the user's Grok routine UI represents named timezones and weekend runs. Do not silently convert a date-only catalyst to an exact release time. Configure crypto weekends independently. The app reports all routines as unverified until the account has installed and observed them.

Twelve Data troubleshooting: Settings → Connections reports server key/display configuration, which does not prove the provider accepted the key. A missing key must be added as `MARKET_DATA_API_KEY` under this project's Edge Function Secrets. Do not prefix it with `VITE_`. Authentication failures back off for ten minutes; request-limit or network errors leave prices unavailable or retain the previous timestamp. Inspect sanitized quote reasons and Edge runtime status, and compare account usage with `private.quote_budget` through an administrator connection. Never print the key or raw provider errors. Set `TWELVE_DATA_DISPLAY_ALLOWED=false` to stop price display immediately.

Asset operations: `assets.identity_verified=false` records an unconfirmed report reference. Before enabling prices, verify its actual instrument/class/venue/currency/expiry, update the catalog through an administrator session, and add an exact `asset_aliases` candidate for `twelve_data`. Do not mark `verified_at` manually: a validated quote sets it. No application client can promote identities or change provider aliases. The free-plan cadence scales with candidate mapping count; additional accounts sharing the key can still exhaust its quota.
